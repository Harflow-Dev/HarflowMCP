# Documentation conventions

- Keep `README.md` focused on the product: purpose, current capabilities and limitations, prerequisites, getting started, and links to maintained guides.
- Put version history, release notes, fixes, migration milestones, and other change records in `CHANGELOG.md`. Do not use the README as a changelog or implementation-progress log.
- Link to `CHANGELOG.md` from the README. Keep detailed current behavior and technical guidance in `docs/`.
